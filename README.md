# MVC Project
Proyecto para recordar y practicar con la arquitectura MVC, añadir autenticación con Identity....

## Iniciando el proyecto
1. Instalo paquetes necesarios para utilizar Entity Framework e Identity desde el administrador de paquetes de NuGet:

- Microsoft.EntityFrameworkCore - versión 10.0.15
- Microsoft.AspNetCore.Identity.EntityFrameworkCore - versión 10.0.15

2. Configuro Identity en el DbContext
